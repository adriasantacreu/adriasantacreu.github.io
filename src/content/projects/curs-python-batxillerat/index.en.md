### Motivation
Learning to program in high school is often reduced to abstract syntax disconnected from tangible utility. This curriculum bridges computational thinking with practical problem solving, enabling students to build functional software from term one.

### Technical solution
The syllabus is organized around an open repository featuring 7 progressive modules: fundamentals (variables, control flow), data structures, modular functions, file I/O, and an applied introduction to basic data analysis and plotting. Designed for interactive environments (Jupyter Notebooks / VS Code).

### Key features
* **Practical focus**: Each module concludes with an applied mini-project (physical simulations, terminal games, or list processors).
* **Step-by-step guides**: Clear annotated examples highlighting best practices and debugging skills.
* **Formative assessment**: Transparent rubrics assessing code functionality, readability, and structural elegance.

### Impact
Actively taught in class at Institut Escola Sant Pol de Mar, empowering students with zero prior programming experience to create real applications and develop confident logical autonomy.
