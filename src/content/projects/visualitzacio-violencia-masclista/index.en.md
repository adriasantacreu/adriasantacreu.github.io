### Motivation
Statistical tables buried in administrative reports can obscure critical social patterns. This project transforms open public datasets into intuitive, accessible visual charts that convey the real scope of gender-based violence transparently.

### Technical solution
Built using lightweight web standards (HTML5, modern JavaScript, and Canvas/SVG rendering libraries). The application processes cleaned official registries and presents dynamic time series and interactive maps without heavy server overhead.

### Key features
* **Interactive exploration**: Multi-parameter filtering by timeframe, assistance category, and geographical district.
* **Accessible visual design**: High-contrast color scales and responsive typography optimized for readability across devices.
* **Source transparency**: Direct attribution and linkages to official open data portals.

### Impact
Provides a useful open-access educational and community resource for evidence-based discussions on public social issues.
